# 多端同步

SteamGuard 使用你自己的 WebDAV 网盘同步加密令牌。无需搭建服务器，也不需要注册 SteamGuard 云账号。可以使用坚果云或其他提供标准 HTTPS WebDAV 的服务；服务套餐、流量与请求额度由网盘提供方决定。

## 第一台设备

1. 解锁保险库，进入“设置 → 多端同步”。
2. 选择坚果云，或填写其他网盘的完整 HTTPS WebDAV 地址。
3. 填写网盘账号及其**应用密码**，点击“查找已有同步库”。坚果云地址预设为 `https://dav.jianguoyun.com/dav/`；应用密码在网盘的第三方应用管理中创建，参见[坚果云官方授权说明](https://help.jianguoyun.com/?p=2064)。
4. 如果列表中已有你要使用的库，选中它并填写该库的独立同步密码，点击“加入并同步”。
5. 网盘还没有库时，将“连接方式”改为“创建独立同步库”，设置至少 12 个字符的独立同步密码，再点击“创建并同步”。已有库时另外创建需要明确勾选确认。
6. 等待最近同步时间更新。保存同步库编号和同步密码，供其他设备加入。

网盘中的应用目录为 `steamguard-sync-v1/<同步库编号>/`，兼容已创建的库。建议使用专用网盘应用密码，并把 WebDAV 地址指向你允许应用读写的目录。支持 HTTPS Basic 账号认证；仅支持 Digest、浏览器 OAuth 或验证码认证的服务暂不可用。

## 其他设备

创建或解锁本机保险库，填写相同的 WebDAV 地址和网盘凭据，点击“查找已有同步库”。对照第一台设备显示的编号，选择**同一个库**，填写它的独立同步密码，点击“加入并同步”。空保险库会读取云端令牌；本机有令牌时会与云端合并。本机保险库主密码可以与其他设备不同。

列表不会解密或展示各库的令牌内容。存在多个库时请按完整编号选择；密码相同也不会自动合并不同编号的库。网盘不支持列目录时，可勾选“手动输入同步库编号”，从第一台设备复制编号后加入。

## 已经误建了两个同步库

例如手机库里有令牌，电脑误建了另一个空库：

1. 在手机“设置 → 多端同步”查看当前同步库编号。
2. 在电脑点击“选择其他同步库合并”，等待已有库列表。
3. 选择与手机编号一致的库，填写**手机库创建时的独立同步密码**。
4. 点击“合并并切换到所选库”。电脑会先同步当前库的最新数据，再保留本机令牌、合并所选库，随后将本机后续同步切换到该库。
5. 对照两端的同步库编号，确认一致，再点击“立即同步”。如有同字段冲突，在冲突列表中选择要保留的版本。

两个库都有令牌时也可按此方式合并。重复令牌按密钥匹配，保留本机标识；HOTP 主设备不会因切换库而自动转移。源库已有冲突时，先处理冲突再切换。目标库密码错误或下载失败时，保留原连接；若本机已完成合并但首次上传失败，页面会显示新库和错误，可点击“立即同步”重试。

原云端库不会自动删除，也不会成为新库的别名。仍连着原库的其他设备，需要先完成同步，再同样切换到选定库。所有设备统一后，如需清理旧库，应先保留独立加密备份，再自行从网盘删除旧编号目录。

## 同步规则

- 同步令牌密钥、算法参数、显示名称、分组，以及 Steam 手机确认所需的认证器信息与恢复信息。
- Steam 登录会话、access/refresh token、导入文件中的原始会话对象、网盘凭据及设备快捷访问配置**不上传**。每台设备分别登录 Steam。
- 解锁后、回到前台、令牌或分组变更后以及前台每分钟尝试同步。锁定、免密码预览、后台或应用关闭时不进行定时同步。系统对后台运行的限制不会影响本地验证码生成。
- 暂停后保留配置、云端数据和 HOTP 主设备限制；可以手动“立即同步”。断开后保留本机令牌和云端同步库，本机恢复独立使用。
- 离线时可以继续管理本机令牌，恢复联网后再合并。不同字段的并发修改自动合并，同一字段的不同修改保留为冲突，需明确选择版本。
- 删除会传播到其他设备。离线重命名不会让已删除令牌自动复活；在原设备重新添加相同令牌可能产生“保留或删除”的冲突。
- 同一 SteamID 的不同认证器密钥不会被静默替换。请先在原设备确认哪份有效，并删除失效令牌后重试同步。

同步会传播误删，因此应同时保留[自动备份及独立导出](BACKUP.md)。同步库包含合并历史，不是云端回收站；若需要删除历史中的旧令牌数据，请在所有设备断开后删除整个网盘同步库，再创建新的同步库。

## HOTP 主设备

TOTP 和 Steam 验证码由时间生成，可在多台设备查看。HOTP 使用递增计数，离线设备无法安全地共同分配下一个计数。

首次加入同步的 HOTP 由当前设备担任主设备，其他设备隐藏验证码、禁止复制和递增。在设置中可以将主设备切换到本机，操作前必须停止旧设备使用并让两台设备完成同步。离线旧设备无法被远程禁用。并发的主设备切换会保留为冲突，计数合并取较大值，避免回退。

## 加密与存储

- 客户端使用 Argon2id 派生同步密钥，参数为 19 MiB 内存、2 次迭代、1 路并行；每个同步库使用独立随机盐。
- 云端状态使用 AES-256-GCM、随机 nonce，并把同步库编号和文件用途绑定到认证数据。云端不保存同步密码或派生密钥。
- 传输只支持 HTTPS，验证证书与主机名，并拒绝 HTTP 重定向。网络模式沿用设置中的系统代理、直连或手动代理。
- 网盘凭据及同步密钥只随本机保险库加密保存。手动导出和自动快照不携带同步配置，恢复后需要重新连接。
- 从 iOS 系统备份或设备克隆恢复时，设备标识缺失或变化会断开原同步配置，避免两台设备共享同一同步身份。请重新加入同步库。
- 网盘仍能看到目录编号、文件大小、访问时间与网络请求。同步密码强度决定离线猜测的难度，请妥善保管并保留独立备份。忘记同步密码无法从网盘恢复令牌；仍可从已解锁设备导出，再建立新同步库。

底层采用 [Apache OpenDAL](https://opendal.apache.org/) 的 WebDAV 实现和 [Automerge](https://automerge.org/) 的合并历史。每次上传新的不可变加密检查点，回读校验成功后才清理已包含的旧检查点；同时上传的新版本会留到下一轮合并，避免覆盖其他设备的变更。历史随检查点保留，达到大小限制后需导出备份并创建新同步库。

## 连接失败时

- “网盘拒绝访问”：检查应用密码、WebDAV 权限和套餐限制。网盘网站登录密码不一定能用于 WebDAV。
- “未找到同步库”：确认 WebDAV 根目录和同步库编号与第一台设备完全一致。
- “同步密码错误，或云端文件已损坏”：核对独立同步密码。它不是保险库主密码，也不是网盘应用密码。
- 新版会自动处理坚果云首次创建目录时的父目录缺失响应。操作被拒绝时，提示中会给出失败步骤与 HTTP 状态；请保留该状态以便排查。
- “连接同步网盘失败”：检查 HTTPS 证书、代理和地址是否为 WebDAV 接口。普通网页登录地址、要求浏览器验证码的页面和重定向地址不可用。
- 网盘请求限制或临时断网：本机令牌仍可使用，稍后重试。写入未确认时会保留旧版本。

首版提供 WebDAV；OneDrive、Google Drive、Dropbox 的专用 OAuth 登录尚未接入，不能把其普通分享链接当作 WebDAV 地址使用。iCloud 系统备份仍用于灾难恢复，不参与跨平台实时合并。

本地验证使用独立的 WebDAV 协议测试服务及合成令牌，覆盖认证失败、加密校验、并发上传、离线修改、删除、冲突、云端回退恢复、空设备加入、误建库合并及往返切换。1.3.1 已使用合成令牌通过坚果云真实服务的加密上传、第二设备读取、修改合并和检查点清理验证；1.3.2 补充通过了真实服务的同步库发现验证；其他服务、配额及 LiveContainer 实机网络仍需在对应环境验证。

## 服务图标与头像

1.5.0 起，令牌头像与名称、分组分别合并。服务图标仅保存图标编号，自定义图片会在本机裁剪为小尺寸 PNG，再进入加密保险库与同步文件；不会请求第三方头像服务器。

使用头像同步前，请将所有设备升级到 1.5.0 或更新版本。旧版本仍可使用原有令牌；收到含头像字段的新同步记录时会拒绝应用，不会覆盖现有数据。通用 OTP 链接、二维码和原软件格式不携带本应用的自定义头像；请使用 `.sgvault` 备份或 WebDAV 同步迁移。
