SteamGuard v1.1.0 手机体验与快捷访问，发布者 kasen。

- 重做手机版布局：清晰的验证码卡片、底部导航和底部弹窗，扩大文字与按钮，适配手机横竖屏、安全区和键盘。
- 关闭应用页面的手势缩放，并统一手机输入框字号，避免输入时自动放大。
- 新增「设置 → 快捷访问 → 免密码预览令牌」：下次打开直接查看、复制验证码，完整保险库保持锁定。登录、交易确认、管理、导入导出和 HOTP 递增仍需解锁。
- 新增指纹 / Touch ID / Face ID 解锁：通过系统认证进入完整保险库，取消或不可用时可使用主密码。
- 两项均为本机可选设置，默认关闭；首次启用需确认主密码。两项同时开启时先进入只读预览，再按需解锁。主密码与已有加密保险库不变，支持覆盖升级。
- Android 使用 Keystore 与绑定加密操作的强生物认证；iOS 使用设备绑定 Keychain 与当前生物特征集合。主密码不写入设备存储。更改指纹或 Face ID 后需用主密码重新启用认证。
- 预览采用独立密钥，只缓存生成验证码所需的数据，不包含 Steam 会话、交易确认密钥和恢复码；令牌库更新会刷新缓存，旧缓存无法继续使用。关闭预览清除缓存与设备密钥。

启用免密码预览后，能打开应用的人都能查看、复制验证码。请根据手机使用环境选择。生物认证需要系统已录入相应特征；Android 仅支持 Class 3 强认证。桌面版仍使用主密码。LiveContainer 的 Keychain / Face ID 能力由容器提供，无法保证所有容器版本兼容，主密码始终可用。此功能用于本机保险库解锁，不替代 Steam 双重验证。

下载对应平台的文件：

- **Android**：`android-universal.apk` 可直接安装，包含 ARM64/x86_64，使用 kasen 长期发布密钥签名；`.aab` 供分发平台使用，不能直接安装。旧调试版签名与正式版不同，升级前请导出加密备份；若系统要求卸载，重装后再导入备份。后续正式版沿用同一密钥。
- **Windows x64**：选择 `-setup.exe` 或 `.msi`。应用与安装器均使用 kasen 自签名代码证书签名；该证书不属于系统默认信任的证书机构，系统仍可能显示未知发布者或 SmartScreen 提示。随附 `.cer` 仅用于检查签名身份，不需要将其导入系统受信任根证书库。
- **macOS**：Apple Silicon 选择 `_aarch64.dmg`，Intel 选择 `_x64.dmg`。采用 ad-hoc 签名，尚未取得 Apple Developer ID 公证，首次打开可能需要在“隐私与安全性”中允许。
- **iOS / LiveContainer**：选择 `ios-arm64-LiveContainer.ipa`，直接导入 LiveContainer；这是标准 `Payload/*.app` 真机 IPA，不是 `.xcarchive` 或模拟器包，也不能按普通已签名 IPA 直接安装。

`SHA256SUMS` 可核对下载完整性；`fingerprints.json` 和公开证书可核对 Android/Windows 的签名身份。私钥、证书密码及真实令牌备份均不作为 Release 附件发布。

发布检查包括原生加密与权限边界回归、界面和手机布局测试、平台构建及签名检查。本版使用合成令牌验证快捷访问，不执行真实交易或改变 Steam 令牌绑定。Windows/Android 真机网络、LiveContainer 内运行、新绑定、短信转移、解绑与真实交易批准/拒绝仍需对应设备和业务场景验证；未用测试账号执行交易或改变令牌绑定。
