# 令牌备注与备用恢复码

通用令牌的「管理」内可以展开「备注与备用恢复码」。这些字段均为可选，不影响验证码生成；Steam 自身的恢复资料仍由 Steam 功能管理。

备注最多 4096 个字符；每个令牌可保存 100 个网站提供的备用恢复码，每个最多 256 个字符。支持逐行添加、隐藏或显示、删除，以及标记已使用。恢复码由对应网站签发，应用只保存和管理，不生成可供网站使用的恢复码。

## 读取与复制

只有展开详情时，界面才从已解锁的原生保险库读取这些内容。折叠或离开页面会清空编辑器状态，恢复码下次展开仍默认隐藏。详情不会进入令牌列表、免密码预览、桌面托盘或组件数据。

复制使用原生接口按令牌和恢复码编号读取，不把任意文本交给复制接口。已使用的恢复码不能复制。复制后的自动清除时间使用应用的剪贴板设置。

保存、标记操作会检查详情版本。其他操作或设备已更新详情时，旧编辑器会提示重新打开，避免覆盖较新的修改。删除需要点击「保存备注与恢复码」，已使用标记则即时保存。

## 备份与迁移

备注、恢复码及使用状态随保险库一起加密，自动备份与应用加密备份完整保留。恢复或导入重复令牌时，备注只补充空值，恢复码按内容合并；同一码只要有一份记录为已使用，合并结果仍为已使用。恢复历史备份不会把已使用的码重新激活。

Google 迁移二维码和标准 `otpauth` 二维码没有这些扩展字段，使用这些格式导出不会携带备注或备用恢复码。需要完整迁移时使用应用的加密备份。

旧保险库不含新增字段时默认读取为空，无需手动迁移。已有资料会随下一次保存保留；请勿再用旧版应用打开含新字段的保险库，以免旧版重新保存时丢失扩展资料。

## 多端同步

备注和每个恢复码独立同步，可以合并不同设备对不同内容的离线修改。删除会同步到其他设备；同一字段发生冲突时需要选择版本。冲突列表只展示字段名称、是否使用或删除、是否为本机版本，不显示备注正文和恢复码内容。

不同设备分别添加相同恢复码时会合并为一项，并保留已使用状态。启用详情同步前，应先更新所有加入该同步库的设备；旧版无法识别新同步字段，会拒绝读取含这些字段的同步文档。
