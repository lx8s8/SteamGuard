# v1.0.0 发布前检查

本次检查覆盖加密持久化、登录与锁定边界、网络错误脱敏、导入限制、原生 IPC 权限、依赖和分发流程；不能替代所有设备与真实账号业务场景的测试。

修复：

- 令牌重命名、删除、排序、HOTP 递增和导入改用加密持久化事务。写入失败恢复内存原值，避免界面与磁盘状态分离；用实际文件写入失败验证回滚，创建失败也清除解锁密钥。
- 登录会话保存前在持有令牌库锁时再次校验锁定世代；二维码请求结束后同样检查锁定世代。会话保存失败取消本次原生登录，退出必须先成功保存。会话在持有令牌库锁时才读取，避免并发退出后旧会话被写回；旧锁定世代的登录回调不能取消重新解锁后建立的新会话。
- 恢复文件按修改时间从旧到新应用，减少旧转移检查点覆盖新值的风险。
- 移除前端不需要的通用 opener IPC 权限，外链由原生命令限制为 Steam 官方 HTTPS 域名。
- 发布过程固定 Android/Windows 签名身份，校验签名指纹，仅收集明确列出的安装器与公开证书，并为所有附件计算 SHA-256。Windows 校验安装器内的应用，包含 MSI 提取及 NSIS 静默安装/卸载；不把 Tauri 打包后还原的未签名中间构建文件当作分发应用。

依赖检查：

- `npm audit`：未发现已知漏洞。
- `cargo audit` 的 `RUSTSEC-2023-0071` 涉及 RSA 私钥运算时间侧信道；应用只构造 `RsaPublicKey`，使用 Steam 公钥加密密码，没有 RSA 私钥或解密接口，不在受影响使用范围。保留标准库实现，不自行重写密码学算法；后续继续跟踪 [上游公告](https://rustsec.org/advisories/RUSTSEC-2023-0071.html)。
- GTK/glib 与 D-Bus 的告警来自 Tauri Linux 依赖：本项目 Release 不构建 Linux 原生应用。`glib::VariantStrIter` 相关不健全实现及上游维护状态仍需在新增 Linux 支持时处理，不将整个跨平台锁文件描述为零告警。

真实账号仅验证登录、会话用途及只读确认查询。新绑定、转移、解绑和真实交易确认未执行；UI 回归使用明确的合成测试桥接，不能等同于每个平台实机联调。

本机验证：27 项原生测试、11 项界面测试、3 项发布收集测试通过；Clippy 全目标零警告。5 项需要私有备份、真实账号或公网环境的测试默认不在 CI 运行。


## v1.0.1

统一未知 SteamID 的语义，增加未知账号绑定必须具有本地令牌验证码证明的检查，保留真实跨账号拒绝。登录未完成时不再保存先前会话，新挑战清除旧的原生会话/审批缓存。只在验证码被 Steam 接受后记录本地验证证明；邮箱/手机批准本身不证明一个缺失 SteamID 的本地密钥属于该账号。

31 项 Rust 测试、14 项界面测试和 3 项发布测试通过；模拟协议验证错误码 88 可恢复、同一挑战重试及服务器时间更新。原始 MPO 私有测试确认其 SteamID 为占位值，授权账号真实登录后再验证原生绑定、加密保存与解锁。真实交易和账号令牌变更未执行。
