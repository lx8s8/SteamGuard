# v1.0.0 发布前检查

本次检查覆盖加密持久化、登录与锁定边界、网络错误脱敏、导入限制、原生 IPC 权限、依赖和分发流程；不能替代所有设备与真实账号业务场景的测试。

修复：

- 令牌重命名、删除、排序、HOTP 递增和导入改用加密持久化事务。写入失败恢复内存原值，避免界面与磁盘状态分离；用实际文件写入失败验证回滚，创建失败也清除解锁密钥。
- 登录会话保存前在持有令牌库锁时再次校验锁定世代；二维码请求结束后同样检查锁定世代。会话保存失败取消本次原生登录，退出必须先成功保存。会话在持有令牌库锁时才读取，避免并发退出后旧会话被写回；旧锁定世代的登录回调不能取消重新解锁后建立的新会话。
- 恢复文件按修改时间从旧到新应用，减少旧转移检查点覆盖新值的风险。
- 移除前端不需要的通用 opener IPC 权限，外链由原生命令限制为 Steam 官方 HTTPS 域名。
- 发布过程固定 Android/Windows 签名身份，校验签名指纹，仅收集明确列出的安装器、开源许可证和校验和，并为所有附件计算 SHA-256。Windows 校验安装器内的应用，包含 MSI 提取及 NSIS 静默安装/卸载；不把 Tauri 打包后还原的未签名中间构建文件当作分发应用。

依赖检查：

- `npm audit`：未发现已知漏洞。
- `cargo audit` 的 `RUSTSEC-2023-0071` 涉及 RSA 私钥运算时间侧信道；应用只构造 `RsaPublicKey`，使用 Steam 公钥加密密码，没有 RSA 私钥或解密接口，不在受影响使用范围。保留标准库实现，不自行重写密码学算法；后续继续跟踪 [上游公告](https://rustsec.org/advisories/RUSTSEC-2023-0071.html)。
- GTK/glib 与 D-Bus 的告警来自 Tauri Linux 依赖：本项目 Release 不构建 Linux 原生应用。`glib::VariantStrIter` 相关不健全实现及上游维护状态仍需在新增 Linux 支持时处理，不将整个跨平台锁文件描述为零告警。

真实账号仅验证登录、会话用途及只读确认查询。新绑定、转移、解绑和真实交易确认未执行；UI 回归使用明确的合成测试桥接，不能等同于每个平台实机联调。

本机验证：27 项原生测试、11 项界面测试、3 项发布收集测试通过；Clippy 全目标零警告。5 项需要私有备份、真实账号或公网环境的测试默认不在 CI 运行。


## v1.0.1

统一未知 SteamID 的语义，增加未知账号绑定必须具有本地令牌验证码证明的检查，保留真实跨账号拒绝。登录未完成时不再保存先前会话，新挑战清除旧的原生会话/审批缓存。只在验证码被 Steam 接受后记录本地验证证明；邮箱/手机批准本身不证明一个缺失 SteamID 的本地密钥属于该账号。

31 项 Rust 测试、14 项界面测试和 3 项发布测试通过；模拟协议验证错误码 88 可恢复、同一挑战重试及服务器时间更新。原始 MPO 私有测试确认其 SteamID 为占位值，授权账号真实登录后再验证原生绑定、加密保存与解锁。真实交易和账号令牌变更未执行。

## v1.1.0

快捷访问通过项目内原生插件实现，不向 WebView 暴露通用的 Keychain / Keystore 读写命令或保险库解密密钥。启用必须在完整解锁状态下再次验证主密码；设置替换先关闭旧授权，系统操作失败保持关闭。认证进行时加互斥锁，锁定世代改变会拒绝过期结果。

生物认证保存的是已派生的保险库密钥和盐，不保存主密码。Android AES-256-GCM Keystore 密钥要求每次强生物认证，通过 BiometricPrompt.CryptoObject 授权实际加解密，录入变更使密钥失效；禁止应用数据自动备份。iOS Keychain 使用 WhenPasscodeSetThisDeviceOnly + biometryCurrentSet，不同步到 iCloud；每次读取使用新 LAContext，无认证复用。没有生物特征、认证取消、锁定或密钥失效时保留主密码回退，不静默绕过验证。

免密码预览使用另一个随机密钥及 AES-GCM 缓存，只包含令牌显示信息和 OTP 参数；不复制 identity_secret、steam_data、会话、设备 ID 或恢复码。预览命令不解锁 Vault，也不恢复 Steam 会话。完整权限仍由 Rust 的 Vault.ensure 检查，而非前端开关；HOTP 不允许在预览中递增。预览绑定当前加密库的 SHA-256，任何更新使旧快照失效；写入失败不影响保存新 Steam 令牌。关闭时先禁止访问，再删除缓存与设备密钥。

参考 [Android 生物认证与 CryptoObject](https://developer.android.com/identity/sign-in/biometric-auth)、[Apple biometryCurrentSet](https://developer.apple.com/documentation/security/secaccesscontrolcreateflags/biometrycurrentset)。不能保证越狱/root 设备或所有 LiveContainer 版本的系统安全服务行为。桌面快捷访问未开放。

发布前本机检查：33 项 Rust 原生测试、21 项界面/布局测试及 3 项发布测试通过；Clippy 与格式检查通过。Android ARM64 调试 APK 和 iOS ARM64 模拟器应用构建成功，iOS 已启动检查页面。生物认证成功/取消的界面回归使用合成桥接；真实手机生物特征和 LiveContainer 内认证仍需对应设备验证。

## v1.2.0

自动快照直接保存主密码加密后的保险库内容，不保存主密码或设备快捷访问凭据。快照失败不回滚已保存的令牌，错误在设置中展示；轮换仅清理严格匹配命名规则的普通文件，读取拒绝路径穿越、符号链接和超大文件。保留最近 10 个变更快照和最多 30 个每日检查点，关闭自动生成不会删除历史备份。

历史恢复要求已解锁当前保险库，并用备份的主密码解密。恢复补回缺失令牌和分组，保留当前 HOTP 较大计数及当前 SteamID 对应令牌，不覆盖当前 Steam 会话。锁定界面只提供加密快照的导出，不向前端返回令牌密钥。分组数据保存在加密保险库并参与事务回滚。

iOS 的 Application Support 数据允许系统备份，device-only 子目录使用 NSURLIsExcludedFromBackupKey 排除；快捷访问密钥仍保存在设备绑定安全存储中。应用不访问 Apple 账号，也不宣称能够开启或检测 iCloud 上传。Android 保留禁用系统云备份的设置。1.2.0 起的应用数据与更早版本相互隔离，通过显式加密导出和导入迁移，不尝试跨沙箱读取旧数据。

本机验证包括加密快照轮换、备份失败保留已保存令牌、HOTP 不回退、保留当前 Steam 令牌、重复令牌分组合并及分组上限事务回滚。Android 新标识 APK、iOS 新标识模拟器构建已通过；iOS 模拟器检查了保险库与 device-only 的显式备份属性。该检查不等同于 iCloud 上传或 LiveContainer 系统备份实测。

1.2.0 本机最终检查：38 项 Rust 测试、25 项界面/手机布局测试、4 项发布测试通过；Clippy、Rust 格式与 Actionlint 检查通过。

## v1.3.2

同步库发现仅列举应用的 `steamguard-sync-v1/` 下符合 UUID 规则的目录，不读取令牌内容、不创建目录；凭据仅在 Rust 内使用，不返回 WebView。列举失败仍可手动输入已知编号加入；创建独立库同时由原生层检查已有库并要求明确确认。

切换前同步源库，目标下载、解密及校验成功后才以保险库事务替换配置并合并，密码错误保留原连接。切换不删除源云端库，也不改动其余设备配置。同一进程重新加入时使用独立的导入历史身份，避免重复 Automerge 序列；HOTP 原主设备标识随导入保留，防止只读设备因切换库取得生成权限。

回归覆盖空设备加入同一个库、原生层拒绝无确认重复建库、两个不同密码的库合并、错误密码重试、往返切换、HOTP 只读保持、手机列表与弹窗布局。

本机检查：58 项 Rust 测试、32 项界面/布局测试及 11 项发布测试通过；Clippy、格式、Actionlint 与前端构建通过。另以合成令牌在坚果云真实服务验证同步库列举、加密往返及第二设备合并，测试库已清理。未读取或合并用户实际令牌数据。

## v1.4.0

Google 迁移使用现有 Prost 依赖解码经过大小限制的 Protobuf。批次编号、总张数、序号及重复页面内容必须一致；缺页时不创建可提交预览，文本导入执行同样的完整性检查。未知版本、无效计数、不支持的算法及损坏内容不会部分写入保险库。导入预览在 Rust 中保存，WebView 仅接收名称、数量与批次进度；扫码得到的原始 URI 暂存于页面内存，离开页面清除引用，不写浏览器持久存储或日志。

关闭导入窗口会丢弃对应的原生预览，窗口关闭后才返回的文件或扫码预览也会立即丢弃；锁定清除所有预览，清理时擦除令牌密钥。原生预览准备阶段检查锁定世代，拒绝锁定后返回的旧解析结果。图片解码限制文件大小、像素与码数量，画布像素在识别后清理；动态识别模块与匹配的 WebAssembly 随应用打包，CSP 只新增本机资源、图片 blob、媒体 blob 与 WebAssembly 编译所需权限，保留外部脚本、iframe 和任意网络请求限制。

手机相机采用 Tauri 官方插件。Android 附带 ML Kit 识别模型，关闭不使用的震动权限并将相机硬件设为可选；iOS / macOS 提供相机用途说明，iOS 提供相册用途说明。停止、关闭、后台、超时或权限失败时释放相机，迟到的系统授权不能留下正在运行的相机流。

本机回归使用公开的 RFC 合成密钥与生成的二维码，覆盖多码乱序、缺页、去重、混批、冲突页、算法、HOTP 计数、原生预览原子提交、批量图片、单图多码、权限拒绝、取消与迟到授权。正式前端在打包 CSP 下离线识别验证通过；Android 调试包内的模型、权限及相机可选标志已经核验，iOS 原生集成构建及模拟器启动通过。这些检查不等同于所有手机摄像头或 LiveContainer 实机验证。

本机最终检查：68 项 Rust 测试、39 项界面/布局测试及 11 项发布测试通过；Clippy、格式、Actionlint 与前端构建通过。新增扫码与备份适配验证均使用合成数据，未使用用户实际令牌或二维码。
